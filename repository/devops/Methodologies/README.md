# DevOps Methodologies

DevOps culture, principles, and ways of working — written so a **beginner can learn DevOps correctly** before drowning in tools.

**Timeless narrative:** durable mindsets (flow, feedback, learning, ownership, safe change) outlive vendors. [19](./19_Durable_Mindsets_And_Evolving_Toolsets.md) maps evolving tool examples; replace tool rows over time — keep the mindsets.

**Authority we align to:** *The DevOps Handbook* / Three Ways ([IT Revolution](https://itrevolution.com/articles/the-three-ways-principles-underpinning-devops/)), **CALMS**, [DORA metrics](https://dora.dev/guides/dora-metrics/) + [capabilities](https://dora.dev/capabilities/) (24-capability map), DevOps Foundation-style maps (Agile / Lean / ITSM / toolchain / DevSecOps), [Microsoft Learn — What is DevOps?](https://learn.microsoft.com/en-us/devops/what-is-devops), [Red Hat — DevSecOps](https://www.redhat.com/en/topics/devops/what-is-devsecops), Lean value-stream practice ([AWS DVSM](https://docs.aws.amazon.com/prescriptive-guidance/latest/strategy-devops-value-stream-mapping/introduction.html)).
