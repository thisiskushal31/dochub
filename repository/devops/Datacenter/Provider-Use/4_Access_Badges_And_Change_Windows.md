## 1. Concepts

Physical access is a controlled product: **badges**, **escorts**, **mantraps**, and **change windows**.

| Job | Notes |
|-----|-------|
| Provision badge | Identity proof; renewals |
| Visitor / vendor access | Escort rules |
| Notify maintenance | Generator/CRAH windows |
| Schedule install | Dock + cage time |

Identity culture on-ramp: [../11_Identity_Access_And_Change.md](../11_Identity_Access_And_Change.md).

## 2. Advanced concepts

### Failure modes

| Failure | Impact |
|---------|--------|
| Expired badge mid-outage | Delay |
| Unescorted vendor | Security incident |
| Ignoring facility notices | Surprise “power event” |
| Too many badged people | Audit risk |
| Hot change without ticket | Blame later |

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| New hire | Badge + escort orientation |
| Install day | Dock booking + badge list + ticket |
| Maintenance season | Subscribe notices; freeze risky deploys |
| Audit | Access list review |

**Staff checklist**

- Badge list current  
- Notices subscribed  
- Escort rules known  
- Change tickets for intrusive work  
- Never prop doors or loan badges  

**Good:** current access, noticed windows, ticketed work. **Bad:** surprise tests; badge sprawl; silent cage entries.
