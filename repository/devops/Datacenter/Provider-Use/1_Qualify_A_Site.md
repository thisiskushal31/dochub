## 1. Concepts

**Qualify** means decide whether a hall/campus fits the workload before signing. Durable checklist—not a persona story.

| Lens | Ask |
|------|-----|
| **Latency** | To users, peers, cloud regions |
| **Interconnect** | Carriers, IX, Fabric-class, cloud on-ramps |
| **Density** | kW/rack, liquid readiness |
| **Power independence** | A+B landing truth |
| **Cooling** | Air vs liquid zones |
| **Hands / access** | SLA, hours, escort rules |
| **Risk** | Flood, seismic, political, power grid |
| **Certs** | Honest Tier/Rated/ISO use |
| **Commercial** | Lead times, exit terms |

Markets research: [Markets/3](../Markets-And-Operators/3_Research_Any_Operator.md).

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| Shortlist 2–3 sites | Same scorecard columns |
| AI row | Density+liquid+weight gate first |
| Hybrid | Colo qualify + cloud region pair |
| Walkthrough | Photo MMR path, PDU, intake |

**Staff checklist**

- Scorecard filled  
- Building not just metro  
- Cloud adjacency measured or estimated  
- Hands trial considered  
- Never sign on Tier sticker alone  

**Good:** scorecard diligence. **Bad:** logo shopping; kW without cool.
