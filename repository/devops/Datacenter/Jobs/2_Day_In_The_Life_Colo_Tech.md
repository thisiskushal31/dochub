## 1. Concepts

A **colo / DC tech** day is rounds + tickets + hands—physical truth in white space and plant rooms you are cleared for.

### Typical loop

| Block | Work |
|-------|------|
| Start | Handover, alarms, maintenance calendar |
| Rounds | Temps, leaks, doors, debris, EPMS glances |
| Tickets | Remote hands, installs, break/fix |
| Evidence | Photos, serials, elevation updates |
| End | Handover, open risks |

Tracks: White-Space, Electrical/Mechanical literacy, Provider-Use hands patterns.

## 2. Advanced concepts

### Failure modes

| Failure | Impact |
|---------|--------|
| Skipping rounds | Silent leak/heat |
| Vague tickets accepted | Wrong U work |
| Ignoring LOTO limits | Injury |
| No photo evidence | Disputes |

### How it connects

Safety [7](./7_Safety_LOTO_And_EPO.md). Escalation [6](./6_Ticket_Taxonomy_And_Escalation.md). Integration failure drills.

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| New tech week-1 | Shadow rounds; one supervised hands ticket |
| Quality bar | Photo checklist mandatory |
| Heat event | Inlet walk + facilities page |
| Audit | Cage housekeeping standard |

**Staff checklist**

- Badge/area clearance known  
- Elevation tools ready  
- PPE/LOTO boundaries  
- Never improvise electrical beyond authorization  

**Good:** disciplined rounds + precise hands. **Bad:** ticket cowboy; ignored alarms.
