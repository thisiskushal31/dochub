## 1. Concepts

Questions that transfer across Equinix-class, regional colo, enterprise, and hyperscale interviews—testing **jobs and independence**, not brand trivia.

### Sample prompts (ask or answer)

| Theme | Prompt |
|-------|--------|
| Power | Walk utility→DIMM; where can A/B falsely meet? |
| Cooling | CRAH vs plant; what happens if one CRAH dies at N? |
| Fabric | Dual-home vs two ports on one ToR |
| Storage | Multipath + why snaps ≠ backups |
| Colo | Contents of a good Smart Hands ticket |
| Taxonomy | Equinix vs Linode vs OVH vs AWS |
| Safety | LOTO energy sources on a UPS-fed rack |
| Docs | Read this one-line: where is the SPOF? |
| Honesty | What won’t a hyperscaler tell you? |

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| Candidate screen | 4 prompts from different themes |
| Self-study | Answer aloud with diagrams |
| Panel | One live one-line read |
| Colo vs cloud role | Emphasize Provider-Use vs Cloud IAM |

**Staff checklist**

- Score independence thinking  
- Require taxonomy clarity  
- Include one safety question  
- Never hire on buzzwords alone  

**Good:** diagram-first answers. **Bad:** acronym salad; Equinox.
