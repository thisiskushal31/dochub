## 1. Concepts

When you change country or landlord, documents look different—**jobs stay**: find A/B split, EPO matrix, elevation U direction, V/Hz, demarc.

Integration skills: [Integration/9](../Integration/9_Reading_A_One_Line_And_Elevation.md), [Integration/10](../Integration/10_Units_Voltage_Frequency_Literacy.md).

### Day-1 doc pack request

| Doc | Why |
|-----|-----|
| Power one-line (relevant slice) | Independence |
| Rack elevation template | Hands accuracy |
| EPO / emergency matrix | Safety |
| Maintenance calendar | Change awareness |
| Network demarc / XC inventory | Hybrid |
| Access rules | Badge reality |

## 2. Advanced concepts

### Failure modes

| Failure | Impact |
|---------|--------|
| Assume NEMA/US norms | Wrong connectors |
| Trust marketing one-line | Fake 2N |
| Skip translation of critical safety | Injury risk |
| Ignore local LOTO form | Work rejected / unsafe |

### How it connects

Markets research [Markets/3](../Markets-And-Operators/3_Research_Any_Operator.md). Provider-Use access [Provider-Use/4](../Provider-Use/4_Access_Badges_And_Change_Windows.md).

### Global variants

Language, title blocks, IEC vs ANSI symbols—ask locals to walk one rack with you on day one.

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| Expat / travel tech | Doc pack + escorted walk |
| New colo landlord | Compare demarc sheet to last site |
| Acquisition | Normalize elevations into your CMDB |
| Audit | Field vs paper deltas |

**Staff checklist**

- V/Hz/connectors confirmed  
- U numbering confirmed  
- Safety briefing done  
- Never energize from assumed pinouts  

**Good:** humble day-1 verification. **Bad:** imported folklore; skipped safety brief.
