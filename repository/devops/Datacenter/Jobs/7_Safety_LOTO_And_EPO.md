# 7 — Safety: LOTO and EPO

## 1. Concepts

**LOTO** (lockout/tagout) isolates energy so people can work. **EPO** sheds defined loads in emergencies. Global jobs; **local code is a variant**—never import another country’s informal habits.

Deep device: [Electrical/13](../Electrical/13_EPO_And_Safety_Disconnects.md). Arc flash literacy via PPE boundaries on gear.

## 2. Advanced concepts

### Failure modes

| Failure | Impact |
|---------|--------|
| Incomplete energy list (battery/UPS/gen) | Re-energize surprise |
| EPO as reboot tool | Mass outage |
| Untrained operation | Injury / termination event |
| Defeat interlocks | Catastrophe |

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| Any power work | Permit + LOTO + verify zero |
| New site | EPO matrix training day-1 |
| Vendor work | Confirm their LOTO integrates with yours |
| Drill | Tabletop EPO zones—not live mash |

**Staff checklist**

- Training current before touch  
- All sources listed  
- EPO authority known  
- Never joke with mushroom buttons  

**Good:** trained, permitted, verified isolation. **Bad:** cowboy breakers; EPO folklore.
