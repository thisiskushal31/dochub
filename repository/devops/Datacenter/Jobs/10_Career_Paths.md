## 1. Concepts

Common progressions (not ladders-as-destiny):

| Path | Arc |
|------|-----|
| **Facilities** | Tech → critical facilities → site/facility engineering |
| **NOC** | Analyst → incident lead → ops management |
| **Hands / field** | Tech → senior hands lead → vendor mgmt |
| **Bare metal** | Ops admin → platform/hypervisor → SRE-adjacent metal |
| **Fabric** | Cabling → DC network eng → architecture |
| **Cross** | Tech who learns Compute; admin who learns hall |

Role map: [1](./1_Role_Map.md).

## 2. Advanced concepts

### Failure modes

| Failure | Impact |
|---------|--------|
| Skipping safety foundation | Dangerous “promotion” |
| Staying tool-only | Can’t change metros |
| Ignoring taxonomy | Stuck in one product world |
| Burnout heroics | Attrition |

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| 6-month plan | Pick path; assign tracks |
| Lateral move | Map overlapping chapters |
| Manager | Dual path mentoring (plant + metal) |
| Colo tenant eng | Provider-Use + Compute blend |

**Staff checklist**

- Path named with track list  
- Safety before electrical depth  
- Metro-transfer skills prioritized  
- Never gatekeep on one OEM brand  

**Good:** deliberate path + portable literacy. **Bad:** title chasing; brand lock-in.
