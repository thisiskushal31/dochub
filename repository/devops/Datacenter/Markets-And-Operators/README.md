# Markets and operators

[← Datacenter](../README.md)

Who builds and sells halls worldwide: **operator kinds**, regional hubs, how sites are set up and run, and how to research an unfamiliar logo. Living majors + minor/regional checklist: **syllabus Part E** (private)—not duplicated as a public phone book.

**Equinix** (not “Equinox”) is the interconnection colo *archetype*—not the only model. Linode/Akamai-class brands are **tenant API clouds** → [Cloud/](../../Cloud/README.md); plant that hosts them is still this folder’s physics.
