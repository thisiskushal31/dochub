## 1. Concepts

MEA capacity and interconnect are growing quickly. Illustrative hubs:

| Area | Notes |
|------|-------|
| **UAE (Dubai/Abu Dhabi)** | Regional interconnect + cloud on-ramps |
| **Saudi Arabia** | Large capacity builds; vision-scale campuses |
| **Qatar / neighbors** | Regional presence |
| **South Africa (Johannesburg/Cape Town)** | Teraco-class interconnection; cloud regions |
| **Broader Africa** | Africa Data Centres, Raxio, MainOne/MDXi-class, national players |

Climate and power (water, heat rejection, grid) shape mechanical design—same jobs as Mechanical track, different stress.

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| GCC users | UAE/KSA shortlist + cloud regions |
| SA users | Teraco-class + cloud ZA regions |
| Multi-country Africa | Expect multiple operators; index them |
| Dense GPU | Confirm liquid/power SKUs explicitly |

**Staff checklist**

- Climate/power constraints asked  
- Cable/cloud adjacency checked  
- Local compliance mapped  
- Hands model tested  
- Don’t treat MEA as one latency blob  

**Good:** country-specific design, verified openings. **Bad:** brochure MW; ignoring water/power; one-city-for-continent.
