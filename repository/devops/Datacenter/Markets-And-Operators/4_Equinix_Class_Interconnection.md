## 1. Concepts

**Equinix** (spelling matters) is the archetype of **carrier-neutral interconnection colo**: retail IBX-style halls, dense MMR ecosystems, remote hands, and interconnection products (cross-connects, metro, Fabric-class).

Peers in spirit include Digital Realty (incl. Interxion in EU), CoreSite-class US interconnection, Telehouse, and others—same *kind*, different footprints.

### Product ideas (jobs, not UI tour)

| Product idea | Job |
|--------------|-----|
| **Cabinet / cage / suite** | Space + power |
| **Cross-connect** | Physical interconnect |
| **Smart / remote hands** | Scoped physical tasks |
| **Fabric / metro interconnect** | Software-defined interconnect between sites/clouds (operator product) |
| **xScale / wholesale-class** | Larger footprints for hyperscale-ish tenants |

Durable order/access jobs: [Provider-Use](../Provider-Use/README.md).

## 2. Advanced concepts

### Failure modes / misconceptions

| Mistake | Reality |
|---------|---------|
| Equinix = only DC company | One kind among many |
| Fabric replaces Networks knowledge | Product ≠ BGP textbook |
| Smart Hands = unlimited labor | Scope and SLA bound |
| IBX and xScale identical | Different sales motions |
| Portal UI immortal | Learn objects, link official docs |

### How it connects

Physical MMR: [Fabric-Physical/5](../Fabric-Physical/5_MMR_And_Cross_Connect_Physical.md). Compare wholesale: [5](./5_Wholesale_And_Hyperscale_Landlords.md). Regional hubs name where IBX-density is strong.

### Global variants

IBX metro coverage is wide but not infinite—always check the specific IBX and carriers present.

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| Interconnect-heavy workload | Equinix-class hub metro |
| Learn the model | One IBX tour + XC + hands ticket drill |
| Compare peer | Same checklist on Digital Realty / CoreSite-class |
| Hybrid cloud | Fabric/on-ramp into cloud ([Provider-Use/7](../Provider-Use/7_Land_Cloud_On_Ramp.md)) |

**Staff checklist**

- Spell Equinix correctly  
- Know IBX vs wholesale-class product  
- XC diversity planned  
- Hands SOP templates ready  
- Don’t treat Fabric portal as plant encyclopedia  

**Good:** interconnection-first site choice, dual XC, clear hands scope. **Bad:** Equinox; assuming every city has same ecosystem; unlimited hands myth.
