## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| EU interconnect | FRA/AMS/LON matching peers |
| Cloud+colo hybrid | DUB/FRA/etc. per cloud region map |
| Bare metal | OVH/Hetzner regions + network product |
| Diversity | Two metros for DR, not two racks only |

**Staff checklist**

- Metro vs building diligence  
- Energy/lead-time questions for large kW  
- Residency requirements mapped  
- Index updated  
- Don’t assume AMS peering equals every Amsterdam postcode  

**Good:** hub chosen for peers+cloud+law. **Bad:** EU-as-one; ignoring power queues.
