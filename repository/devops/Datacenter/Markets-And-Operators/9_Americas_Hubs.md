- Carrier/IX density differs by campus inside the same metro—check the building  
- Cloud region adjacency ≠ automatic low-latency XC  
- LatAm hubs growing; verify current on-ramps officially  
- Market reporting churns—dual-source MW claims

## 3. Applications and use cases

| Goal | Pattern |
|------|---------|
| US interconnect | Ashburn or metro matching users/peers |
| Canada residency | Toronto/Montreal shortlist |
| Brazil | São Paulo campuses + cloud regions |
| Diversity | Two buildings / two operators when risk requires |

**Staff checklist**

- Metro purpose (interconnect vs wholesale) clear  
- Building-level carrier check  
- Hands/portal trial  
- Index logos used  
- Don’t treat “Virginia” as one failure domain  

**Good:** building-specific diligence. **Bad:** metro-name magic; one campus as “the US.”
