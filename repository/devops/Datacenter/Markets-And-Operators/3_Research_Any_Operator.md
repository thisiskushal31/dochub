## 1. Concepts

Goal: faced with an unfamiliar logo, **classify**, estimate metro prominence, name architecture shape, and name the durable jobs—without claiming a complete building directory of Earth.

### Brochure / diligence checklist

| Question | Why |
|----------|-----|
| Taxonomy kind ([1](./1_Operator_Taxonomy.md))? | Product shape |
| Metros / campuses listed? | Footprint |
| Retail colo vs wholesale vs both? | What you can buy |
| kW/rack and liquid options? | Density fit |
| MMR / carriers / IX / Fabric-class? | Interconnect |
| Remote / Smart Hands SLA? | Ops model |
| Who owns BMC / ToR / cage network? | Support boundary |
| Certs / Rated / Tier language? | Honest use only |
| Power path / A+B landing? | Independence |
| Portal objects (inventory, tickets, XC)? | Day-2 ops |
| Financial / ownership (if material)? | Risk |

Add the logo to the **syllabus living index** the same session when possible.

## 2. Advanced concepts

### Failure modes of research

| Failure | Impact |
|---------|--------|
| Marketing Tier as topology proof | False comfort |
| Press-only claims without dual source | Bad metro bets |
| Ignoring who owns ToR | Ticket ping-pong |
| Assuming global brand = local MMR strength | Wrong hub choice |
| Skipping latency to users/cloud | Pretty site, wrong place |

### Prominence literacy

Count carrier density, cloud on-ramps, IX presence, and published campus MW—not Instagram. Dual-source commercial claims; label market reporting when needed.

**Staff checklist**

- Kind + ownership boundary written  
- Dual-source big claims  
- Latency/cloud adjacency checked  
- Hands/portal model known  
- Index updated  

**Good:** checklist-driven, indexed, humble about secrets. **Bad:** brochure belief; phone-book cosplay; one press release.
