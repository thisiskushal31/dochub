# Podman

Podman is a daemonless, rootless container runtime with a CLI that is largely compatible with Docker. You can use many Docker commands as-is (e.g. `podman run`, `podman build`). Podman does not require a long-running daemon or root privileges, which can simplify security and resource usage.
