# Docker Swarm

Docker Swarm is Docker’s built-in orchestration mode. You initialize a swarm on one or more nodes and deploy services (replicated containers) that Swarm schedules and keeps running. It is simpler than Kubernetes and fits small clusters or teams that already rely on Docker.
