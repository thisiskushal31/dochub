# Installation

This topic points to where installation is covered in the official OpenShift Container Platform documentation. All procedures and platform-specific steps are in the Red Hat docs; this file summarizes the structure and how to find the right guide.

---

## Installation overview

The official documentation includes:

- **Installation overview** – high-level install content and how the process works.
- **Supported platforms** – where you can run OpenShift Container Platform clusters.
- **Selecting a cluster installation type** – choosing between installer-provisioned infrastructure (IPI) and user-provisioned infrastructure (UPI), and other options.

You can deploy clusters on infrastructure that the installation program provisions and the cluster maintains, or on infrastructure that you prepare and maintain. The install method and prerequisites depend on the platform.

---

## Supported platforms (from the 4.21 index)

The docs describe installation on:

- **Public cloud:** Alibaba Cloud, AWS, Azure, Azure Stack Hub, Google Cloud, IBM Cloud (including IBM Cloud Bare Metal Classic).
- **On-premises / flexible:** Assisted Installer (on-premise), Agent-based Installer (on-premise), bare metal, Nutanix, OpenStack, Oracle (Database Appliance, Distributed Cloud, Edge Cloud), VMware vSphere.
- **Special topologies:** Single-node, two-node clusters.
- **Any platform** – generic “install on any platform” guidance.

Each platform has its own install flow (e.g. account permissions, quotas, DNS, load balancers, and post-install validation). Use the official guides for your target environment.

---

## Installation configuration and validation

- **Installation configuration** – cluster-wide configuration during installation.
- **Validation and troubleshooting** – validating and troubleshooting an OpenShift Container Platform installation.

For exact steps, prerequisites, and troubleshooting, use the Red Hat documentation for your OpenShift version and platform.

---

## Updates and migration

After install, the **Update and migrate** section covers:

- **Updating clusters** – upgrading OpenShift Container Platform clusters.
- **Migrating from version 3 to 4** – migration path and Migration Toolkit for Containers.
