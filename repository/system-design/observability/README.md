## Quick reference

- **Health** — Is it up and ready? Liveness and readiness for orchestration and load balancing.
- **Availability** — Uptime and success rate over time; SLOs and error budgets.
- **Performance** — Latency, throughput, errors; dashboards and symptom-based alerts.
- **Security** — Auth events, access to sensitive data, anomalies.
- **Usage** — Feature and tenant usage; capacity and billing.
- **Instrumentation** — Metrics, logs, traces (e.g. OpenTelemetry); structured and sampled.
- **Distributed tracing** — Trace requests across services; spans, trace id, context propagation.
- **Visualization and alerts** — Dashboards and actionable alerts with runbooks.
