# Data Science & AI Deep Dive

Home for **how a question becomes a prediction or an answer**: representation, learning, adaptation, retrieval, control, evaluation, safety, serving.

Vector *engines* live in [Databases-Deep-Dive](https://github.com/thisiskushal31/Databases-Deep-Dive). Feature *tables* and pipelines live in [Data-Engineering-Deep-Dive](https://github.com/thisiskushal31/Data-Engineering-Deep-Dive). Library hello-worlds (PyTorch, Jupyter, LangChain) live in [Tooling Data-ML](https://github.com/thisiskushal31/Tooling-and-Frameworks-Deep-Dive/tree/main/Data-ML). Gateways and scale live in [System-Design-Concepts](https://github.com/thisiskushal31/System-Design-Concepts).

Layers in this tree are meant to outlive a model family. Today’s product names go in [Instances](./Instances/README.md). New here? Start at [Foundations](./Foundations/README.md), or jump to [Representation](./Representation/README.md) and [Retrieval-And-Grounding](./Retrieval-And-Grounding/README.md) if you are building one retrieval system.
