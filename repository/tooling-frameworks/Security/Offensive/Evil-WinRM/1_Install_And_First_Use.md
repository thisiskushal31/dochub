# Evil-WinRM — install and first use

[← Evil-WinRM](./README.md)

## Install

```bash
# Ruby gem — see https://github.com/Hackplayers/evil-winrm
gem install evil-winrm
evil-winrm -h
```

## First lab use

```bash
evil-winrm -i 192.168.56.10 -u labuser -p 'LabOnly!'
```

Lab credentials and hosts only.
