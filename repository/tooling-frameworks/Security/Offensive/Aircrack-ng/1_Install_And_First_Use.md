# Aircrack-ng — install and first use

[← Aircrack-ng](./README.md)

Wi-Fi security auditing suite. **Lab / authorized targets only — never against systems you do not own.**

## Install

```bash
brew install aircrack-ng   # or apt install aircrack-ng
aircrack-ng --help
```

## First lab use

Only against **your** AP / RF lab. Capture and crack lab WPA handshakes per official tutorials. Never target neighbors or cafés.

## For / not for

| For | Not for |
|-----|---------|
| Personal Wi-Fi lab audits | Unauthorized wireless attacks |
