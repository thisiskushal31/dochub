# Mimikatz — install and first use

[← Mimikatz](./README.md)

## Install

Download only from trusted releases discussed in [gentilkiwi/mimikatz](https://github.com/gentilkiwi/mimikatz) documentation / release notes. Transfer into an **isolated lab** Windows VM. AV will often quarantine — expected in labs.

## First lab use

Run inside the lab VM per upstream examples (e.g. privilege / sekurlsa demos on **your** test machine). Pair findings with defensive detections (credential access ATT&CK techniques) in Security-Deep-Dive Defensive-Ops — do not treat this as a tutorial for unauthorized access.

## Warning

Unauthorized use can be illegal. Keep scope written and local.
