# WinPEAS — install and first use

[← WinPEAS](./README.md)

Windows privilege-escalation enumeration scripts/binaries from PEASS-ng. **Lab / systems you own only.**

## Install

Download current release assets from [PEASS-ng / winPEAS](https://github.com/peass-ng/PEASS-ng) (prefer official releases). Transfer only into **your** lab Windows VM.

## First lab use

Run the binary/script appropriate to your lab image (exe vs batched forms change across releases — follow the repo README). Review output for misconfigs, tokens, and service paths; pair with [Impacket](../Impacket/README.md) / [BloodHound](../BloodHound/README.md) only in authorized labs.
