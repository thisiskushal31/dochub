# subfinder — install and first use

[← subfinder](./README.md)

## Install

```bash
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
# or: brew install subfinder
subfinder -version
```

## First lab use

```bash
subfinder -d example.com -silent
```

Use on **your** domains or lab brands only.
