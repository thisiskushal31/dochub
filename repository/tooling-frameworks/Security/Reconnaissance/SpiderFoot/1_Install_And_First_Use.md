# SpiderFoot — install and first use

[← SpiderFoot](./README.md)

Automated OSINT recon UI/CLI. **Lab / authorized targets only — never against systems you do not own.**

## Install

```bash
pipx install spiderfoot
# or clone https://github.com/smicallef/spiderfoot
spiderfoot -h
```

## First lab use

Start UI against localhost; scan a domain you own/lab. Review modules enabled before running.
