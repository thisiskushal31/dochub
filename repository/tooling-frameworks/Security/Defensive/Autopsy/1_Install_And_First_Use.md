# Autopsy — install and first use

[← Autopsy](./README.md)

GUI digital forensics platform (The Sleuth Kit under the hood). **Lab images / systems you own only.**

## Install

| OS | Typical |
|----|---------|
| macOS / Windows / Linux | Installer from [sleuthkit.org/autopsy](https://www.sleuthkit.org/autopsy/) |

Follow the vendor install doc for Java dependencies on your OS.

## First lab use

1. Create a case.  
2. Add a **disk image** from your lab VM (not a live foreign disk).  
3. Run ingest modules selectively (start small).  
4. Review timeline / file hits; export notes into your IR case template.
