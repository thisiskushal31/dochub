# Velociraptor — install and first use

[← Velociraptor](./README.md)

## Install

Follow [Velociraptor docs](https://docs.velociraptor.app/) for current server/client packages (GUI release builds). Prefer a dedicated **lab** VM; do not enroll third-party endpoints.

## First lab use

1. Stand up a lab server per upstream quickstart.  
2. Enroll one lab client you own.  
3. Run a canned artifact (e.g. process list) and export results into your IR case notes.

Heavy — start only when you want agent-based DFIR practice beyond osquery.
