# TheHive — install and first use

[← TheHive](./README.md)

## Install

Use current [TheHive Project](https://thehive-project.org/) / StrangeBee docs (Docker Compose is the usual lab path). Versions and compose files change — copy from official docs, not from memory.

## First lab use

1. Bring the stack up in lab.  
2. Create an organization + user.  
3. Open a case from a sample alert; attach observables.  

Workflow automation into TheHive can use [n8n](../../../Automation/n8n/README.md) — do not fork n8n under Security.
