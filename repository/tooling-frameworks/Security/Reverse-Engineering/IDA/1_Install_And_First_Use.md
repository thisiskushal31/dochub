# IDA — install and first use

[← IDA](./README.md)

## Install

Obtain **IDA Free** or a licensed IDA Pro build from [Hex-Rays](https://hex-rays.com/ida-pro/). No redistributed binaries in this repo.

## First lab use

Open a lab binary; run auto-analysis; inspect functions. Use Ghidra/radare2/Cutter when you need a fully open toolchain.
