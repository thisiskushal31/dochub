# Zitadel

[← Identity](../README.md)

Capability: **Multi-tenant IdP (OIDC/SAML/SCIM-oriented)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 4–8, 13, 16).

Go-based identity platform often chosen for B2B multi-tenant SaaS. License is AGPL-3.0 for the server — read obligations before distributing.
