# Dex

[← Identity](../README.md)

Capability: **OIDC broker / federating IdP** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 5, 7, 16).

CNCF sandbox OIDC provider that brokers to upstream connectors (LDAP, SAML, GitHub, Google, …). Common in front of Kubernetes tooling. Not a full user-management IdP.
