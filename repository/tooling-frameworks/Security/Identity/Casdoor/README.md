# Casdoor

[← Identity](../README.md)

Capability: **All-in-one UI IdP (OIDC/SAML/CAS/SCIM)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 4–7, 13, 16).

Go + React UI IdP with broad social login connectors and SCIM. Useful when you want a batteries-included admin UI quickly.
