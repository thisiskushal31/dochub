# Teleport

[← Identity](../README.md)

Capability: **Identity-aware access (SSH/K8s/DB/web)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 9, 11, 15, 16).

Certificate-based access plane replacing shared SSH keys/VPNs for engineers. **Community Edition** is the OSS lab path; Enterprise adds governance features (e.g. some SCIM).
