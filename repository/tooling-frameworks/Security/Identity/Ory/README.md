# Ory

[← Identity](../README.md)

Capability: **Headless identity stack (Kratos + Hydra + …)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 4–8, 14, 16).

Apache-2.0 building blocks: **Kratos** (identities/login/recovery APIs), **Hydra** (OAuth2/OIDC server), plus Keto/Oathkeeper. You bring the UI. Managed option: Ory Network.
