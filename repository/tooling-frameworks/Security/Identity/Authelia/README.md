# Authelia

[← Identity](../README.md)

Capability: **Forward-auth / SSO portal (+ OIDC provider)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 3, 8, 9, 16).

Lightweight companion to reverse proxies (Traefik, nginx, Caddy, …) for SSO/2FA in front of self-hosted apps. Not a full enterprise SAML IdP.
