# oauth2-proxy

[← Identity](../README.md)

Capability: **Reverse-proxy OIDC gate** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 5, 8, 9, 16).

Puts OIDC login in front of arbitrary HTTP apps (nginx auth_request, standalone proxy). Pairs with any OP (Keycloak, Dex, Google, …).
