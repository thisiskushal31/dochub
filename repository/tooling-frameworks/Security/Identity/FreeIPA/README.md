# FreeIPA

[← Identity](../README.md)

Capability: **Linux IdM (LDAP + Kerberos + DNS + CA)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 13, 15, 16).

Integrated identity/policy/audit for Linux realms (389-ds, MIT Kerberos, Dogtag, …). Prefer a disposable VM — heavyweight vs Kanidm for small labs.
