# Casbin

[← Identity](../README.md)

Capability: **AuthZ library (ACL/RBAC/ABAC)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 14, 16).

Embeddable authorization library with many language ports and model files. Good when you want authZ *inside* the app without a separate PDP service.
