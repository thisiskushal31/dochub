# authentik

[← Identity](../README.md)

Capability: **IdP + flows + outposts (OIDC/SAML/LDAP/RADIUS)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 3–7, 13, 16).

Self-hosted IdP with visual flows and outposts for apps that lack native SSO. MIT core; some enterprise features separately licensed — read the license for your build.
