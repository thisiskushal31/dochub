# Kanidm

[← Identity](../README.md)

Capability: **Rust identity for Linux/infra (OIDC, LDAP, RADIUS, SSH keys)** (open source — see license on upstream). Program depth: [Security-Deep-Dive Identity](https://github.com/thisiskushal31/Security-Deep-Dive/tree/main/Identity) (Identity notes 3, 11, 13, 16).

Modern identity server aimed at Unix/Linux estates; passkey-forward. Read-only LDAP for legacy apps. Not a SAML IdP replacement for SaaS sprawl.
