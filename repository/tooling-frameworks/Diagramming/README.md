# Diagramming

[← README](../README.md)

How you **draw** a system — not what to design. Open one of these **while** you read [System-Design-Concepts](../../System-Design-Concepts/README.md). The ideas (HLD, caching, CAP) stay there.

Industry split: *diagramming* (boxes and lines: draw.io, Excalidraw), *diagrams-as-code* (Mermaid, PlantUML), *notation* (C4). All of that lives here.

| Folder | Job |
|--------|-----|
| [Mermaid](./Mermaid/README.md) | Diagrams in markdown |
| [PlantUML](./PlantUML/README.md) | Text UML / C4 plugins |
| [draw.io](./draw.io/README.md) | Drag-and-drop (also diagrams.net) |
| [Excalidraw](./Excalidraw/README.md) | Hand-drawn whiteboard |
| [C4](./C4/README.md) | Context / Container / Component / Code notation |
